## Exposure, geometry and limits

Matching the global key-count vector [14,20,9,21] does not match every history's occupancy. At K8,D64 stable queries, content targets see a mean19.22 following same-module writes, versus18.91 averaged across the five random tables; all see72.50 total following observations. Protected target traces therefore receive19.22 versus18.91 retained decays on average, whereas global traces receive72.50. The complete per-history and target-specific exposure checks pass. These descriptors are not a mediation analysis or a reason to adjust/select the primary histories.

Prospectively computed geometry shows greater mean signed within-module raw-key cosine under content (.06294) than under the random maps (see `router_geometry.csv`). Grouping correlated keys could increase within-module association interference. That is a possible mechanism, not a tested causal explanation of the accuracy differences. Parent-specific feature/decoder geometry, per-stream collisions and read/write allocation remain linked.

Every comparison holds the existing dense-trained encoders/decoder/W0/alpha/raw_eta fixed and starts new zero traces. These are frozen-transfer results from four checkpoints and one synthetic correlated codebook, not independently trained routing efficacy or seed-population uncertainty. Routing changes reading and writing together. The inherited implementation computes all four candidate module updates/reads before masking; one retained active association/read and one-versus-four retained decay applications do not establish arithmetic, FLOP, latency or memory savings. Fast H remains65,536 bytes per stream, plus the fixed512-byte route table outside H.

Do not tune the reference table, eta, gate or maps on these90723 histories and rebrand the same data as a final test. This run supports carrying forward the allocation/decay controls and exposing revision behavior when replacing the reference component with a teammate's actual method. It supports no biological, full-Titans or new-routing novelty claim.
