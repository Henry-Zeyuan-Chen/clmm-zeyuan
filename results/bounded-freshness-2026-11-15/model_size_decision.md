# Model size and the project aim

Decision before the freshness results: retain the existing 81,921 learned-parameter component and 64 KiB adaptive trace state per stream for this comparison. Freezing its capacity and weights isolates the replay intervention. Previous common neutral K16 acquisition was 100% across all twelve checkpoints, so lack of basic capacity is not the demonstrated explanation for obsolete replay damage. That observation does not establish scale invariance or show that a larger model would behave identically.

The current component has four associative modules with nonlinear encoders/decoder and 64×64 traces. It reads typed IDs from a fixed 64-key/16-value codebook. It does not contain the proposal's complete short-term attention, persistent tokens and MAC sequence path. Slow learned parameters, adaptive trace elements, fixed buffers and logical replay records are separate resource categories; 64 KiB is not the total model footprint. Capacity is not adequately described by parameter count alone.

The proposal's broader aim needs a compact complete sequence model, held-out fact assignments and language templates, memory carried across sessions, and acquisition checks before interpreting retention. The existing complete byte-sequence approximation has 839,248 registered parameters and already contains attention/persistent memory; it is distinct from the current 81,921-parameter component. Its finite-set fitting succeeded but assignment transfer failed. Making it larger has not been shown to solve that gap. My next milestone is to integrate the method into that existing path and diagnose held-out acquisition first. A few-million-parameter second capacity is reasonable to profile if that diagnosis supports it, with matched training/state budgets. This is a conditional engineering plan, not an empirically established optimal size or a new training run in the freshness study. See docs/SHARED_PRETRAIN.md and docs/FIXED_SET_GENERALIZATION.md.

The original Titans paper's language-model setup reports 170M, 340M, 400M and 760M parameters; the first three use 15B training tokens and the last 30B. See [Titans v1, section 5.1](https://arxiv.org/html/2501.00663v1#S5.SS1), checked November15,2026. Those published scales are useful context, not a requirement for this course's controlled mechanism study. Matching them would be a distinct pretraining commitment. A small complete-model result with honest scope can be meaningful; a small isolated-memory result cannot be presented as full Titans efficacy.

Progression: (1) finish the causal freshness comparison at fixed capacity; (2) integrate the chosen method into the existing complete sequence path; (3) qualify fresh assignment/template acquisition; (4) compare retention and genuine revisions at matched training, write and state budgets; (5) check a second capacity before making broad scaling claims. The present study performs step1 only.
